# EOD Manager

SkyZone Biloxi closing report for the trampoline park.

Download **EODManager.exe** from [Releases](https://github.com/DudelyStudios/EODManager/releases). Put it in a writable folder (Desktop is fine). Do not copy someone else's `data` folder unless you want the same saved nights.

## Update from inside the app

1. Open **GM Tools → Check for updates**.
2. If a newer version is listed, choose **Install update**.
3. The closer restarts on the new exe. Your `data` folder stays put.

The first copy still has to be installed by hand (email, USB, or this Releases page). After that, parks can update themselves.

## First-time setup

Import the park's current EOD spreadsheet when asked. History and the Excel template come from that import.
